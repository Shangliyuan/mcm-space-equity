# 太空中的收获，属于谁？

2022 MCM/ICM F 题团队论文 **Harvest in Space! Outlook & Equity** 的中文导读与面试复习页面。Team 2224021。

## 内容

- 从研究问题到 HELEN 公平评价体系（五维度、16 个二级指标）
- 参与能力聚类、生产函数与古诺数量竞争的逻辑
- 原文报告的均衡份额、综合指数及监管情景对比
- 模型局限、关联与因果的区别、面试讲述参考
- 原论文 PDF：`paper.pdf`

页面为回顾性说明，不是原模型的计算复现。交互切换展示原文结果，未重新估计参数或求解均衡。未标注无法从论文核实的获奖等级或个人分工。

## 本地阅读

直接打开 `index.html` 即可。也可运行：

```sh
python3 -m http.server 8765
```

访问 http://localhost:8765 。无需构建、安装依赖或外部 CDN。

## GitHub Pages

仓库上传后，在 Settings → Pages → Build and deployment 中选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)`，保存。Pages 可用地址以 GitHub 设置页显示为准。
